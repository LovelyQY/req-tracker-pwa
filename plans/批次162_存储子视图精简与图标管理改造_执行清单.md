### 165.2 importAll()（复用 sanitize 做 XSS 防护）
```javascript
function importAll() {
  var input = document.getElementById('import-icons-file');
  if (!input || typeof RT_PAGE_ICONS === 'undefined') return;
  input.addEventListener('change', function (e) {
    var f = e.target.files && e.target.files[0];
    if (!f) return;
    var reader = new FileReader();
    reader.onload = function () {
      try {
        var data = JSON.parse(reader.result);
        if (!data || !Array.isArray(data.icons)) { toast('导入文件格式错误', 'error'); return; }
        var count = 0, warn = 0;
        data.icons.forEach(function (item) {
          if (item.key && item.svg) {
            var clean = RT_PAGE_ICONS.sanitize(item.svg);
            if (!clean || clean.indexOf('<svg') < 0) { warn++; return; }
            RT_PAGE_ICONS.set(item.key, clean); count++;
          }
        });
        toast('已导入 ' + count + ' 个图标' + (warn ? '（' + warn + ' 个无效已跳过）' : ''), 'success');
        renderList(); if (selectedKey) selectKey(selectedKey);
      } catch (err) { toast('导入失败：' + err.message, 'error'); }
    };
    reader.readAsText(f);
    e.target.value = '';
  });
  input.click();
}
$('btnImport').addEventListener('click', importAll);
```

## 批次166：修复重置确认弹框不显示

### 真实根因（已定位，2026-07-29 执行时实测）
- `.cd-overlay` CSS 完整正确（`overlays.css:101`）→ 样式非根因。
- `customConfirm(...)` 逻辑正确，且在 `app.js` / `storage-backup.js` 均正常工作 → 函数本身非根因。
- **权限守卫猜测已证伪**：grep 确认 `icon-manager.html` / `icon-manager.js` **当前无任何 `data-perm`**（面板「恢复默认」、`批量重置」、列表「恢复」均不带 `data-perm`），故守卫不会拦截重置入口。
- **真正根因 = 列表点击委托的判断顺序错误**：列表项 DOM 为 `.icon-item > … > button.reset`，而原委托先执行 `e.target.closest('.icon-item')` 命中（"恢复"按钮本身位于 `.icon-item` 内部）→ `selectKey()` 并 `return`，**`reset()` 从未被调用** → 点列表"恢复"永远不弹框。面板「恢复默认」按钮（独立于 `#list`，直接绑定）本就正常，但用户最常用的是列表"恢复"，故整体表现为"提示没有弹框"。

### 修复方案（已落地）
- **列表点击委托重排**：先 `e.target.closest('.reset')` 命中则调用 `reset(key)` 并 `return`，否则再 `closest('.icon-item')` 执行选中。
- `reset()` 文案优化：`confirmText: '恢复'` → `'确定重置'`。
- `reset()` 健壮性：`!key` 时 `toast('请先选择一个图标再恢复默认', 'warn')` 替代静默 return（覆盖面板按钮在 `selectedKey` 为空时的死点击）。

### 批次166 验证
- 列表项「恢复」点击 → 弹确认框（标题「恢复默认」/ 正文 / 取消｜确定重置），确认后图标恢复默认
- 面板「恢复默认」点击（已选图标）→ 同样弹框
- 未选图标时点面板「恢复默认」→ 友好 toast 提示，不报错
