## 0. 残损分类与受影响文件总览

两类残损均为解析期语法错误，会使**整段 `<script>` 失效**（DOMContentLoaded 监听、`render()` 等全部不执行 → 页面静态容器在、动态内容永不被渲染）：

| 类别 | 残块形态 | 性质 |
|---|---|---|
| **A 类** | `[c];` + 孤立 `});` + 孤立 `}` | 变量替换残留，c 未定义 |
| **B 类** | `, 2200);` （或 `,2200); }`） | 某次 `setTimeout(..., 2200)` 类调用被损坏残留 |

| 批次 | 现象 | 文件 | 含残损类别 |
|---|---|---|---|
| **123-A** | 页面不显示内容（项目 / 版本 / 公司 / 部门） | `project.html` `project-version.html` `company.html` `department.html` | A + B（两类俱全） |
| **123-B** | 基础数据页为空 / 不显示子项；字典 / 职位 / 人员 / 关于页空白 | `basic-data.html` `dictionary.html` `position.html` `user.html` `about.html` | `basic-data`/`about` 仅 A；`dictionary`/`position`/`user` A + B |
| **123-C** | 更新日志不显示内容 | `changelog.html` | 仅 A |

> 对照：`report.html` 两类残损均无，其报告子项（日报/待办/缺陷/会议）正常显示，证明问题纯属脚本被截断，与路由机制无关。`profile.html`/`security.html` 的同类残损已在批次 122-C 修复。

## 1. 核心 CRUD 页不显示内容（批次 123-A）✅ 已落地

### 1.1 现象
- 进入「项目 / 项目版本 / 公司 / 部门」任一页面：列表区空白，新建/编辑表单无法打开，增删改查全部失效。

### 1.2 根因定位
- 每个页面内联脚本残留两类死代码：
  ```js
  function applyGuard(){ /* ... */ }
  [c];          // A 类：c 未定义，解析期语法错误
    });         // A 类：孤立括号
  }             // A 类：孤立闭合括号
  // ...
  function fmtTime(ts){ /* ... 以 return ...; 收尾 */ }
    }           // （fmtTime 已正常闭合）
    , 2200);    // B 类：setTimeout(...,2200) 被损坏残留
    }           // B 类：孤立闭合括号
  ```
- 两类均为解析期语法错误，各自所在的 `<script>` 块在解析阶段整体失败 → 页面动态内容不渲染。

### 1.3 修改方案
- `batch-fix.sh 123A`：同时删除 A 类（`[c];`+`});`+`}`）与 B 类（`, 2200);`+可选孤立 `}`）残块，不改动任何业务逻辑。

### 1.4 验收
- [x] 4 个页面列表正常渲染，新建/编辑/删除可用。
- [x] `node --check` 抽取的全部内联脚本通过（修复前各文件均有失败脚本块，修复后归零）。

## 4. 执行方式（批次执行器）

脚本 `batch-fix.sh` 按批次号分批次执行，同时清理 A / B 两类残损，幂等且安全：

```bash
./batch-fix.sh 123A            # 仅修复 4 个核心 CRUD 页
./batch-fix.sh 123B            # 仅修复基础数据域 5 页
./batch-fix.sh 123C            # 仅修复更新日志页
./batch-fix.sh all             # 全量修复 3 个批次（10 个页面）
./batch-fix.sh --dry-run 123A  # 预览将要修改的文件，不落盘
```

- **幂等**：已清理的页面再次执行为 no-op，不重复删除。
- **安全**：仅删除 A 类（`[c];`+`});`+`}`）与 B 类（`^\s*,\s*\d+\);\s*}?$` 孤立行）残块，不触碰任何其他逻辑；合法 `setTimeout(fn, 2200)` 调用不会被误删。
- **校验**：执行后脚本自检全仓是否仍存在孤立残损（`config.js` 的 `escapeHtml` 合法下标 `({...})[c]` 与合法 `setTimeout` 不在 HTML 内，不误报）。
- **验证证据**：修复后 10 个页面的全部内联脚本 `node --check` 均通过（修复前各文件均有失败脚本块）。
