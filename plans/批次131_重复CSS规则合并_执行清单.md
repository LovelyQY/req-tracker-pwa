## 0. 总览
合并 `styles.css` 中结构重复的 CSS 规则，约 44 组。

## 1. 现象
- 多处样式因历史各自实现而重复定义，增加修改成本。

## 2. 根因定位（实测）
- 弹窗：`.modal` 出现 9 次；4 个 overlay 各自定义 `.modal`（`#task-detail-overlay .modal` / `#modal-overlay .modal` / `#todo-detail-overlay .modal` / `#todo-modal-overlay .modal`）。
- 主色填充按钮：`.btn.primary`×2、`.cd-btn.cd-confirm`×2 与其它主色按钮样式重复。
- 附件/详情行：`.attachment-info` ≈ `.detail-attachment-info` 两组并存。
- `display:none` 出现 14 处，分散定义；`.is-hidden` 工具类当前未定义。

## 3. 修改方案
- 抽共享 `.modal` 基类（通用定位/背景/圆角/动画），各 overlay 仅覆写差异。
- 抽 `.is-primary-fill` 统一主色填充按钮，原 `.btn.primary`/`.cd-btn.cd-confirm` 等改用该类。
- 合并 `.attachment-info` 与 `.detail-attachment-info` 为一条。
- 新增 `.is-hidden { display:none !important; }` 工具类，替换分散的 `display:none`（非 `@media print` 内的合理使用保留）。

## 4. 验收
- [ ] 上述重复规则合并后，`styles.css` 规则数下降且无未定义类引用。
- [ ] 弹窗、主色按钮、附件行、隐藏元素在各页面视觉与重构前一致。
