## 批次160：图标管理图标容器收敛（蓝色区域贴合图标）

> 范围：仅 `icon-manager.html` 两处。基础数据 / 存储 landing 的图标容器用户已确认 OK，不做改动。

### 160.1 `icon-manager.html` `.icon-item .pv`（列表项图标）

**锚点（行52-55）：**
```css
.icon-item .pv{width:36px;height:36px;flex-shrink:0;display:flex;align-items:center;justify-content:center;
  color:var(--icon-fg);background:var(--icon-bg);border-radius:var(--icon-radius);
  box-shadow:var(--icon-shadow)}
.icon-item .pv svg{width:22px;height:22px}
```
**改动：** `width:36px;height:36px` → `width:32px;height:32px`（22px 图标，约 5px 内边距，适合紧凑列表行）。
**保留：** `--icon-*` 变量引用不变。

### 160.2 `icon-manager.html` `.editor .preview`（实时预览）

**锚点（行67-69）：**
```css
.editor .preview{display:flex;align-items:center;justify-content:center;height:120px;
  background:var(--icon-bg);border-radius:var(--icon-radius);color:var(--icon-fg);margin-bottom:12px}
.editor .preview svg{width:56px;height:56px}
```
**改动：** 去掉 `height:120px` 全宽蓝带，改为**居中方形贴片**包裹 56px 图标：
```css
.editor .preview{display:flex;align-items:center;justify-content:center;width:96px;height:96px;margin:0 auto 12px;
  background:var(--icon-bg);border-radius:var(--icon-radius);color:var(--icon-fg)}
```
（56px 图标 + 约 20px 内边距，蓝底与图标成比例；`margin:0 auto` 使其在编辑面板内水平居中。）

### 批次160 验收

- 实时预览为 96px 方形贴片，蓝底贴合 56px 图标。

## 批次161：数据备份 / 存储与数据 子视图去卡片化（纯分区风格）

> 范围：**仅「数据备份」页（`#backupView`）与「存储与数据」页（`#storageView`）两个子视图的 `.settings-section`**。存储与备份 landing 页（双入口列表）不动。
> 目标：两个子视图去掉「白底+圆角+阴影」卡片感，改为纯分区风格。

### 161.1 子视图 `.settings-section` 本地去卡片（关键：不碰全局 pages.css）

在 `storage-backup.html` 本地 `<style>`（行31 之后）追加覆盖规则（本地 `<style>` 在 `pages.css` 之后加载，同特异性下后定义者胜出）。`#backupView` 与 `#storageView` 的 `.settings-section` 共用同一类，一条覆盖同时生效：
```css
/* 批次161：去卡片化 — 数据备份 / 存储与数据 子视图改为纯分区风格（仅本页生效，不动 pages.css 全局） */
.settings-section{
  background:transparent;
  border-radius:0;
  box-shadow:none;
  padding:4px 0;
  margin-bottom:18px;
}
```
- 抵消 `pages.css:2-8` 的 `background:var(--surface)` / `border-radius:var(--radius-lg)` / `box-shadow:var(--shadow-card)` / `padding:16px`。
- 标题 `h3`、`.backup-tip`、`.backup-actions` 等内部元素无卡片属性，保持不变。

### 161.2 （建议）子视图 `.settings-item` 扁平化

`pages.css:31-38` 的 `.settings-item` 为 `background:var(--surface-soft);border-radius:10px` 的小胶囊行（仅「存储与数据」页有 3 行：已用空间 / 配额上限 / 持久化存储）。若希望彻底无卡片感，可一并扁平（可选，按视觉效果决定）：
```css
.settings-section .settings-item{
  background:transparent;
  border-radius:0;
  border-bottom:1px solid var(--border);
  padding:10px 0;
}
.settings-section .settings-item:last-child{border-bottom:none}
```
- 仅作用于存储页 `.settings-section` 内，不影响其它页。
- 「数据备份」页无 `.settings-item`，此条仅对「存储与数据」页生效。
